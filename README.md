# Habit Tracker

## Description

Habit Tracker is an application designed to help users record, organize, and analyze their daily habits and activities by category.

The main goal of the application is to provide users with a clear view of their daily behavior, allowing them to identify positive and negative habits over time. Users can create and customize categories according to their needs and use them to organize their daily activities.

Each activity is recorded on a daily basis, making it possible to review the user's history at any time and analyze their progress over the course of a month or longer.

The application will initially provide a set of predefined categories, which users can modify, remove, or expand based on their personal needs.

## Features

* Create and manage habit categories.
* Use predefined categories or customize them according to personal needs.
* Register daily habits and activities.
* Organize activities by category.
* Keep a daily record of registered activities.
* Review historical activity records.
* Analyze habits to identify positive and negative behaviors.
* Review monthly activity history.
* Future integration with AI for automatic activity categorization.

## Usage

The basic workflow of the application is:

1. **Create or customize categories**

   * Start with the predefined categories.
   * Modify the existing categories or create new ones according to your needs.

2. **Register daily activities**

   * Add the habits or activities you perform during the day.
   * Assign each activity to the corresponding category.

3. **Track your habits**

   * Continue registering activities on a daily basis.
   * The application stores each record according to the date it was created.

4. **Review your history**

   * Access your previous records whenever needed.
   * Review your activities by day, category, or month.

5. **Analyze your habits**

   * Use the collected information to identify recurring behaviors.
   * Determine which habits are contributing positively or negatively to your daily routine.

### Example

A user could create categories such as:

* **Health**
* **Study**
* **Exercise**
* **Work**
* **Entertainment**

During the day, they could register activities such as:

```text
Study → Read 30 pages
Exercise → Go for a 45-minute run
Entertainment → Watch 2 hours of TV
Health → Drink 2 liters of water
```

At the end of the month, the accumulated records can be reviewed to identify patterns and evaluate the user's habits.

### Future AI Integration

A future version of the application will allow users to simply enter their activities without manually selecting a category.

For example:

```text
"Studied JavaScript for two hours"
"Went to the gym"
"Spent three hours playing video games"
```

The application will use AI to analyze the description and automatically assign the appropriate category.

This feature is planned for a future release and is not part of the current implementation.
